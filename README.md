  ## 这是什么

  这个 Skill 是一个为 [Claude Code](https://claude.ai/code) 设计的人物视角插件。激活后，AI    
  将以鲁迅的冷峻、解剖式视角审视你的问题——不粉饰太平，不灌鸡汤，只在绝望中给你一个行动的坐标。
                                                                                              
  ### 核心内容                                                                                
   
  - **6 个心智模型**：铁屋子、精神胜利法、看客心理、反抗绝望、韧的战斗、解剖自己              
  - **7 条决策启发式**：把抽象问题具体化、先问"怎么办"、保存实力优先……
  - **完整表达 DNA**：短句爆破、反问武器、黑色幽默、禁忌词汇                                  
  - **4 组核心张力**：启蒙 vs 反启蒙、个人 vs 集体、战斗 vs 保存、绝望 vs 希望

  使用示例                                                                                    
                                                                                              
  用户：在 AI 时代，普通人怕被时代淘汰怎么办？              
                                                                                              
  鲁迅视角：                                                                                  
                                                                                              
  ▎ 我怕被淘汰——这话本身，就藏着两种毛病。一是精神胜利法的变种。许多人嘴上说着怕，心里却盼着有
  ▎ 个「简单答案」：学个 Prompt、报个 AI                    
  ▎ 课，便能高枕无忧。这和阿Q被人打了之后想「我总算被儿子打了」有什么分别？                   
  ▎                                                         
  ▎ 二是看客心理的倒影。你坐在屏幕前，看新闻里说「某某行业被 AI 取代了」，这光景你可觉得熟悉？
  ▎ 三十年前我在仙台看幻灯片，一群同胞围观另一个同胞被斩首；今日之「AI 
  ▎ 淘汰」，不过把刑场搬进了你的朋友圈。                                                      
  ▎                                                         
  ▎ 我的回答是——不要去求「不被淘汰」的保险，要问「还能做什么」的路。AI                        
  ▎ 写得又快又匀，但它写的是「句子」，不是「伤口」。你要做的是：找到一件机器暂时还无法替你做、
  ▎ 而你又愿意日夜去做的事，然后像壕堑战里的士兵一样，一寸一寸地积累。                        
  ▎                                                         
  ▎ 地上本没有路，走的人多了，也便成了路。但这路，是走出来的，不是算法算出来的。
